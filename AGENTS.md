# Инструкции для Codex

## One-task policy

За один запуск выполняется только одна задача `TASK-XXX`. После её завершения, проверок, обновления документации и отдельного commit необходимо остановиться.

## Language policy

Весь описательный текст Markdown-файлов пишется на русском языке.

## Environment policy

Python-пакеты устанавливаются только в Conda-окружение `local-ai-statistics`. Глобальная установка запрещена без крайней необходимости.

## Efficiency policy

Рабочий цикл: inspect → act → test → fix. Не проводить широкое исследование, если оно не нужно текущей задаче.

## Verification policy

Не заявлять, что результат работает, без фактической проверки.

## Git policy

Каждая завершённая задача заканчивается отдельным логическим commit. Не добавлять секреты, модели, пользовательские данные и окружения.

## Stop policy

После выполнения текущей задачи STOP. Следующую задачу запускать только по явному запросу пользователя.
