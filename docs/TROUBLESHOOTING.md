# Устранение неполадок

## Ollama недоступен

Запустите `./scripts/healthcheck.ps1`. Скрипт проверяет `127.0.0.1:11434`, `/api/version`, `/api/tags` и OpenAI-совместимый `/v1/models`.

Если endpoint не запущен, используйте `./scripts/start-local-agent.ps1`. При уже работающем Ollama скрипт не останавливает и не перезапускает существующий процесс. `./scripts/stop-local-agent.ps1` останавливает только процесс с PID, созданным самим стартовым скриптом; пользовательский процесс Ollama не затрагивается.

В TASK-005 подтверждён ответ endpoint с `qwen3-coder:30b`. Если запросу требуется рабочий context, передайте `options.num_ctx=16384`; при memory pressure используйте 8192. Не подменяйте модель и не скачивайте baseline без отдельного решения.

Во время проверки model runner работал как `100% CPU`, без Vulkan offload. Это наблюдение, а не неисправность: измерение скорости и выбор дальнейших действий относятся к TASK-006. Полная offline-изоляция ещё не проверена.
