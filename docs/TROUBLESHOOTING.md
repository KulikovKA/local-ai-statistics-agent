# Устранение неполадок

## Ollama недоступен

Запустите `./scripts/healthcheck.ps1`. Скрипт проверяет `127.0.0.1:11434`, `/api/version`, `/api/tags` и OpenAI-совместимый `/v1/models`.

Если endpoint не запущен, используйте `./scripts/start-local-agent.ps1`. При уже работающем Ollama скрипт не останавливает и не перезапускает существующий процесс. `./scripts/stop-local-agent.ps1` останавливает только процесс с PID, созданным самим стартовым скриптом; пользовательский процесс Ollama не затрагивается.

В TASK-003 подтверждён ответ endpoint без моделей. Производительность GPU, загрузка модели и полная offline-изоляция ещё не проверены.
