# Использование

Практический сценарий использования локального агента через боковую панель VS Code будет документирован после его интеграции. Основным рабочим документом останется `.ipynb`, открытый в Jupyter UI VS Code.

Локальная модель доступна как `qwen3-coder:30b`. Проверка `./scripts/healthcheck.ps1` должна показать endpoint `http://127.0.0.1:11434`, loopback-listener и по одной модели в локальном и OpenAI-совместимом API.

До настройки Agent layer используйте только локальный endpoint и передавайте `options.num_ctx=16384` для рабочего context. Не отправляйте запросы к cloud-моделям и не настраивайте AI sidebar до соответствующих задач. Полная инструкция и зафиксированные параметры — в [MODEL_INSTALLATION.md](MODEL_INSTALLATION.md).
