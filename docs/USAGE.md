# Использование

Практический сценарий использования локального агента через боковую панель VS Code будет документирован после его интеграции. Основным рабочим документом останется `.ipynb`, открытый в Jupyter UI VS Code.

До выбора модели Ollama используется только как локальный runtime. Проверка `./scripts/healthcheck.ps1` должна показать endpoint `http://127.0.0.1:11434`, listener loopback и нулевое число моделей. Не отправляйте запросы к cloud-моделям и не настраивайте AI sidebar до соответствующих задач.
