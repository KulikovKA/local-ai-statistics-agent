# Jupyter Notebook

Главный рабочий объект пользователя — `.ipynb`, например `analysis.ipynb`. Он открывается в стандартном Jupyter Notebook UI VS Code: пользователь видит Markdown- и Python-ячейки, outputs, графики и таблицы, вручную редактирует notebook и запускает его kernel.

Локальный AI-агент работает рядом с notebook через боковую панель VS Code. При программном изменении notebook агент использует `nbformat`, Jupytext или другой надёжный API, затем валидирует результат и выполняет предусмотренные ячейки.

Jupytext не является обязательным пользовательским интерфейсом. При необходимости парный `.py` в формате `py:percent` можно создать командой `jupytext --set-formats ipynb,py:percent analysis.ipynb`; это служебное представление для автоматизации, а не замена `.ipynb`. Нельзя редактировать JSON notebook заменой строк.
