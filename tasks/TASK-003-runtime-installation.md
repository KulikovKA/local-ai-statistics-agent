# TASK-003 — Установка локального runtime

## Цель

Подтвердить и оформить runtime, выбранный в TASK-002, обеспечив управляемый запуск локального OpenAI-совместимого endpoint.

## Контекст

Выбор должен быть зафиксирован ADR.

## Разрешено

Проверять существующий выбранный runtime и создавать start/stop/healthcheck scripts без изменения глобальных настроек.

## Запрещено

Скачивать модель до TASK-005.

## Шаги

TASK-002 выбрала уже установленный вне репозитория Ollama. Не переустанавливать, не удалять и не обновлять его без фактического блокера. Подтвердить версию, путь, модельное хранилище, привязку к `127.0.0.1`, отсутствие моделей и cloud configuration; документировать управляемый запуск и выполнить healthcheck endpoint. Не устанавливать модель или VS Code AI-расширение.

## Проверки

Проверить старт, остановку, healthcheck, локальные `/api/*` и `/v1/*` endpoints, недоступность endpoint извне и отсутствие cloud fallback без явной необходимости.

## Артефакты

Скрипты и инструкция установки.

## Definition of Done

Существующий Ollama проверен и оформлен без переустановки, документация и статусы обновлены, создан commit.
