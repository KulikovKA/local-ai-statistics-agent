# TASK-002 — Выбор локального runtime

## Цель

Сравнить зрелые локальные runtime и принять архитектурное решение.

## Контекст

Решение опирается на TASK-001 и нагрузку одного пользователя. Runtime должен предоставлять локальный OpenAI-совместимый endpoint для будущего VS Code Agent layer и не определяет выбор модели.

## Разрешено

Исследовать llama.cpp, Ollama, vLLM и документировать ADR.

## Запрещено

Устанавливать runtime или модели.

## Шаги

Оценить llama.cpp, Ollama, vLLM и иные зрелые варианты по скорости, доступному ускорению, GGUF, локальному OpenAI-совместимому API, offline-эксплуатации и удобству запуска. Зафиксировать ADR без выбора конкретной модели.

## Проверки

Проверить актуальность и ссылки решения.

## Артефакты

ADR и обновлённая архитектурная документация.

## Definition of Done
