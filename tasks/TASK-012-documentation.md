# TASK-012 — Launchers

## Цель

Создать удобные скрипты запуска, остановки и healthcheck локального inference runtime.

## Контекст

Runtime, модель и локальное подключение sidebar уже проверены. Скрипты обслуживают inference layer и не заменяют Jupyter UI или VS Code sidebar.

## Разрешено

Создавать PowerShell-скрипты, а при необходимости Linux `.sh`, и дополнять русскую инструкцию запуска.

## Запрещено

Менять глобальные настройки системы, запускать cloud-сервисы или сохранять в скриптах секреты.

## Шаги

Добавить и проверить `start-local-agent.ps1`, `stop-local-agent.ps1` и `healthcheck.ps1` либо эквивалентные скрипты выбранного runtime. Они должны управлять только локальным endpoint.

## Проверки

Штатно запустить и остановить сервис, проверить healthcheck, привязку к `localhost` и совместимость со sidebar.

## Артефакты

Скрипты и инструкция запуска.

## Definition of Done

Скрипты проверены на фактической конфигурации, статусы и документация обновлены, создан commit.
