# TASK-013 — Публикация на GitHub

## Цель

Безопасно опубликовать public repository, если GitHub CLI авторизован.

## Контекст

Перед публикацией требуется аудит секретов, данных, моделей и приватных путей.

## Разрешено

Проверять репозиторий и при авторизованном `gh` создавать public repository и push.

## Запрещено

Запрашивать пароль или токен в чате.

## Шаги

Провести аудит, проверить `gh auth status`, затем опубликовать при наличии авторизации.

## Проверки

Проверить remote и публичное содержимое.

## Артефакты

Отчёт о публикации или зафиксированный блокер авторизации.

## Definition of Done

Репозиторий безопасно опубликован либо корректно указан требуемый интерактивный вход; создан commit при изменениях.

## Git commit

`chore: prepare github publication`
