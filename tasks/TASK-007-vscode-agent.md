# TASK-007 — Выбор VS Code Agent

## Цель

Проверить и выбрать готовую VS Code-интеграцию для локального AI-агента.

## Контекст

Основной кандидат — официальная актуальная интеграция Qwen Code с боковой панелью VS Code. Конкретные runtime и модель уже установлены, но endpoint на этом шаге не настраивается. Собственное расширение не разрабатывается.

## Разрешено

Исследовать актуальную официальную Qwen Code-интеграцию и готовые альтернативы, если кандидат не подходит. Допускается установить выбранное готовое расширение для проверки его интерфейса; cloud LLM и cloud fallback не допускаются.

## Запрещено

Создавать собственное расширение, настраивать обязательный cloud fallback или выдавать локальному endpoint облачный адрес.

## Шаги

Проверить sidebar внутри VS Code, agent mode, workspace context, native diff, чтение и правку файлов, terminal, Python execution, совместимость с локальной/self-hosted моделью, OpenAI-совместимым endpoint, удобство работы с notebook и возможность офлайн-работы после установки. Зафиксировать причины выбора; настройка endpoint — TASK-008.

## Проверки

Проверить функции расширения в VS Code.

## Артефакты

Конфигурация и инструкция использования.

## Definition of Done
