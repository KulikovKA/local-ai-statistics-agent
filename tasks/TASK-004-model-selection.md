# TASK-004 — Выбор локальной модели

## Цель

Выбрать и технически обосновать локальную модель для основного AI Agent в VS Code.

Основным кандидатом является:

`Qwen3-Coder-30B-A3B-Instruct`

Это MoE-модель:

* 30.5B параметров всего;
* около 3.3B активных параметров на токен;
* специализирована на coding и agentic coding;
* поддерживает tool/function calling;
* рассчитана на интеграцию с Qwen Code.

Главная задача этого этапа — не искать произвольную 7–9B модель вместо неё, а проверить, является ли `Qwen3-Coder-30B-A3B-Instruct` практичным вариантом для текущего ноутбука.

## Целевое железо

Фактические характеристики брать из `docs/HARDWARE.md`.

Ожидаемо:

* AMD Ryzen 7 8845HS;
* 32 GB RAM;
* Radeon 780M;
* без дискретной NVIDIA GPU.

## Основной кандидат

Проверить:

`Qwen3-Coder-30B-A3B-Instruct`

Для GGUF/runtime на базе llama.cpp рассмотреть в первую очередь:

* Q4_K_M;
* Q4_K_S;
* другие разумные 4-bit quantization при необходимости.

Q5 использовать только если по оценке RAM остаётся достаточный запас для:

* Windows;
* VS Code;
* Jupyter;
* Conda;
* inference runtime;
* KV cache;
* agent tooling.

## Критерии

Оценить:

* размер GGUF;
* реальное потребление RAM;
* запас RAM при работе VS Code + Jupyter;
* ожидаемую скорость generation;
* prompt processing speed;
* Vulkan compatibility;
* CPU/Vulkan hybrid inference;
* context requirements;
* KV cache;
* tool calling;
* Qwen Code compatibility;
* качество agentic coding;
* работу с Python;
* пригодность для статистического анализа;
* license.

## Важное ограничение

Не использовать максимальный заявленный context модели как рабочий по умолчанию.

Для локального ноутбука исследовать разумные значения:

* 8K;
* 16K;
* возможно 32K.

Приоритет:

стабильность и скорость agent loop.

## Контрольные модели

Для сравнения разрешается выбрать 1–2 более компактные модели класса примерно 7B–14B.

Они нужны НЕ как основной заранее выбранный вариант, а как baseline для ответа на вопрос:

> Насколько Qwen3-Coder-30B-A3B лучше по качеству и насколько дороже по скорости/RAM?

Не скачивать все модели на этом этапе, если это не требуется.

## Решение

Если анализ показывает, что Qwen3-Coder-30B-A3B в подходящей quantization комфортно помещается в память и ожидаемо пригодна для интерактивного agent workflow:

выбрать её основной моделью.

Если существуют серьёзные технические основания считать её непрактичной:

* недостаток RAM;
* крайне низкая скорость;
* проблемы выбранного runtime;
* проблемы с tool calling;

не менять модель молча.

Зафиксировать проблему и предложить fallback.
