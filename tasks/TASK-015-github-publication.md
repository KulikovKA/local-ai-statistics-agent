# TASK-015 — Публикация на GitHub

## Цель

Безопасно опубликовать public repository, если GitHub CLI авторизован.

## Контекст

До публикации завершены реализация и документация. Необходимо исключить секреты, пользовательские данные, веса моделей, локальные пути и конфигурацию с токенами.

## Разрешено

Проверять репозиторий и при авторизованном `gh` создавать public repository и выполнять push.

## Запрещено

Запрашивать пароль или токен в чате, публиковать секреты, модели, пользовательские данные либо приватные локальные пути.

## Шаги

Провести аудит файлов и Git-истории, проверить `gh auth status`, затем опубликовать репозиторий только при наличии авторизации.

## Проверки

Проверить remote и публичное содержимое. При отсутствии авторизации честно зафиксировать требуемый интерактивный вход.

## Артефакты

Отчёт о публикации или зафиксированный блокер авторизации.

## Definition of Done

Репозиторий безопасно опубликован либо корректно указан требуемый интерактивный вход; создан commit при изменениях.

## Git commit

`chore: prepare github publication`
