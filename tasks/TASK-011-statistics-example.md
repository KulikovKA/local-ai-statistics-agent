# TASK-011 — Проверка офлайн-режима

## Цель

Подтвердить работу VS Code, Jupyter, sidebar агента, local runtime и local model без интернета после первоначальной установки.

## Контекст

Все компоненты уже установлены и локальный agent loop проверен. Offline-проверка должна удостовериться, что inference не уходит в cloud и не зависит от скрытого fallback.

## Разрешено

Временно отключать сетевое подключение либо применять документированный эквивалентный метод изоляции, выполнять локальные сценарии и анализировать конфигурации и журналы без секретов.

## Запрещено

Заявлять офлайн-совместимость без фактической проверки, использовать облачную LLM, отключать защиту системы без необходимости или сохранять токены в репозитории.

## Шаги

В изолированном состоянии открыть `.ipynb` в VS Code, выполнить ячейки Conda kernel и запросить агенту небольшое безопасное действие через sidebar. Проверить, что запрос обслужен `localhost` runtime и локальной моделью.

## Проверки

Зафиксировать метод изоляции, успешность Jupyter и agent-сценария, адрес endpoint, отсутствие cloud fallback и известные ограничения офлайн-режима.

## Артефакты

Обновлённый `docs/OFFLINE.md` с фактическими результатами.

## Definition of Done

Офлайн-сценарий подтверждён или честно документирован блокер; статусы и документация обновлены, создан commit.
