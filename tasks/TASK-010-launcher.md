# TASK-010 — Полный цикл агента

## Цель

Фактически проверить главный acceptance scenario: `read → reason → edit notebook → execute → observe → fix → execute again`.

## Контекст

Локальный VS Code sidebar уже подключён к runtime и модели, а безопасное изменение `.ipynb` проверено в TASK-009. Пользователь задаёт задачу из sidebar; `.ipynb` остаётся его главным рабочим документом.

## Разрешено

Создавать синтетические notebook и `data.csv`, выполнять Python/Jupyter в Conda-окружении и фиксировать traceback, действия и результаты.

## Запрещено

Использовать cloud LLM, подменять выполнение описанием, вручную править JSON notebook строковой заменой или использовать пользовательские данные.

## Шаги

Дать агенту запрос на первичный анализ данных, проверку предпосылок, выбор статистического критерия, добавление ячеек и Markdown-интерпретации. В сценарии должна быть воспроизводимая ошибка: агент наблюдает её, исправляет код и повторно запускает ячейки.

## Проверки

Подтвердить чтение данных и notebook, безопасное изменение `.ipynb`, выполнение через Conda kernel, наблюдение output, исправление ошибки, повторный успешный запуск и наличие интерпретации.

## Артефакты

Воспроизводимый тестовый сценарий, notebook с outputs и отчёт с наблюдаемыми свидетельствами каждого этапа.

## Definition of Done

Полный локальный agent loop подтверждён фактическим сценарием, статусы и документация обновлены, создан commit.
