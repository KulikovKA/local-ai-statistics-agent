# Локальный AI-агент для статистического анализа

Локальный проект для поэтапного создания офлайн AI-агента в VS Code с приоритетом Python, Jupyter и статистического анализа.

## Целевой пользовательский сценарий

Пользователь работает с `analysis.ipynb` в обычном интерфейсе Jupyter Notebook внутри VS Code: видит и редактирует Markdown- и Python-ячейки, запускает их и получает таблицы, графики и другие результаты. Одновременно он обращается к локальному AI-агенту через боковую панель VS Code.

Для слоя агента выбрано официальное расширение Qwen Code Companion для VS Code. Основной интерфейс пользователя — его боковая панель рядом с обычным Jupyter UI; bundled CLI остаётся техническим компонентом и не заменяет sidebar.

## Быстрый старт

После установки Conda создайте окружение командой `conda env create -f environment.yml`, затем активируйте его: `conda activate local-ai-statistics`.

## Принципы

Работа выполняется ровно по одной задаче за сессию. Статус и следующий шаг находятся в `PROJECT_STATE.md`, подробный план — в `TASKS.md`.

## Работа с Jupyter

Главный рабочий объект — файл `.ipynb`, например `analysis.ipynb`. Jupytext и `nbformat` разрешены как внутренние механизмы безопасного программного изменения ноутбука агентом. Парный файл `.py`, если он понадобится, остаётся служебным представлением и не заменяет notebook в пользовательском сценарии.
